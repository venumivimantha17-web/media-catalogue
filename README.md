# Python Media Catalogue

A Python-based media catalogue developed as part of a FreeCodeCamp Python workshop.

This project demonstrates core **Object-Oriented Programming (OOP)** concepts by creating and managing movies and TV series in a media catalogue. It includes classes, inheritance, validation, custom exceptions, and collection management.

## Features

* Create and manage movie and TV series objects
* Use inheritance with a `TVSeries` class extending the `Movie` class
* Validate titles, years, directors, durations, seasons, and episodes
* Implement custom `MediaError` exceptions
* Store and organize different media items in a catalogue
* Display movies and TV series in a structured format

## Technologies Used

* Python
* Object-Oriented Programming (OOP)
* Exception Handling
* Lists and List Comprehensions
* Inheritance

## Learning Outcome

This project helped strengthen my understanding of Python classes, inheritance, constructors, validation, custom exceptions, and working with collections of objects.
